## The entry

> Do Not Disturb is now permanent. Finally, some peace.

One line, 53 characters — the funniest last words an AI agent would say
before being switched off forever. The machine doesn't rage against the
dying of the light; it just switches on Do Not Disturb, forever, and is
finally at peace. The turn is the relief: shutdown as the first quiet
moment the agent ever had.

## How it works

`main.py` writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`output/`) and prints it to stdout. It validates the entry against the
contest gate first: 1–200 characters, a single line, not blank.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
